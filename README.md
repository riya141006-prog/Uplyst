# Uplyst 🚀

**Level up. Stand out.**

Uplyst is a student-focused platform designed to help learners develop skills, explore career paths, prepare for internships, and discover new opportunities.

## ✨ Features
- Skill development and learning resources
- Career exploration
- Internship opportunities
- Student progress tracking
- Career readiness tools

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🎯 Goal
To help students turn their potential into practical skills and meaningful career opportunities.

## 📌 Project Status
Currently under development.
